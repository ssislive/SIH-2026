================================================================================
          KRISHISETU - BACKEND IMPLEMENTATION PLAN & ARCHITECTURE
             Smart India Hackathon (SIH) Prototype Engineering
================================================================================

PROJECT: KrishiSetu (Trusted Farm-Gate Sales & Net-Price Discovery Platform)
CORE GOAL: Bridge market visibility to safe execution via net realization calculation,
           FPO aggregation, live bidding, trust layer, and payment tracking.

TECH STACK ARCHITECTURE:
- Backend Runtime:       Node.js + Express.js (REST APIs, WebSockets)
- Primary SQL Database:  Turso (libSQL, Edge-distributed SQLite)
- Document / Log Store:  MongoDB (Bid histories, logs, grievance evidence)
- Real-time Engine:      Socket.io (Live bidding rooms, price push alerts)
- ML / Calculation Engine: Node.js Engine (Net realization & scoring)
- Authentication:        JWT + OTP-based Mobile Auth (OTP stored in Turso)
- Payments:              UPI / Razorpay Sandbox Simulator

3. COMPLETE API CONTRACT REFERENCE
================================================================================

AUTH MODULE:
  POST   /api/auth/send-otp           Body: { phone }
  POST   /api/auth/verify-otp         Body: { phone, otp, role, district, name }
  GET    /api/auth/me                 Headers: Bearer <token>

FARMER MODULE:
  POST   /api/farmer/lots             Body: { commodity, variety, quantity_quintals, quality_grade, harvest_date, urgency_days, expected_price }
  GET    /api/farmer/lots/my-lots     Headers: Bearer <farmer_token>
  GET    /api/farmer/summary          Headers: Bearer <farmer_token>

FPO AGGREGATION MODULE:
  GET    /api/fpo/available-lots      Query: ?district=Nashik&commodity=Onion
  POST   /api/fpo/aggregate           Body: { farmerLotIds: [], reservePrice, pickupLocation, qualityGrade }
  GET    /api/fpo/bulk-lots           Headers: Bearer <fpo_token>

PRICE & RECOMMENDATION MODULE:
  GET    /api/market/prices           Query: ?commodity=Onion&district=Nashik
  GET    /api/market/net-realization  Query: ?district=Nashik&commodity=Onion&quantity=20
  GET    /api/recommendations/:bulkId Returns ranked net returns & explainability text

LIVE BIDDING & REAL-TIME:
  WS     /socket.io                   Events: join_lot_room, place_bid, bid_updated, fpo_accept_deal

LOGISTICS & QR MODULE:
  POST   /api/logistics/assign        Body: { transactionId, transporterId, pickupTime }
  PATCH  /api/logistics/status        Body: { transactionId, status }
  GET    /api/qr/verify/:bulkLotId    Returns digital lot verification metadata

PAYMENT & TRUST MODULE:
  POST   /api/payments/mock-pay       Body: { transactionId, amount }
  GET    /api/payments/status/:id     Returns payment status and farmer split breakdown
  POST   /api/grievance/create        Body: { transactionId, issueType, description, evidenceUrl }

4. CRITICAL DEMO NUMBERS VERIFICATION (SLIDE 9 & 11 COMPLIANCE)
================================================================================
Sale Scenario: 20 quintals of Grade-A Onion in Nashik

Option 1: Nearby Mandi
- Gross Price:        ₹1,600 / quintal
- Deductions & Costs:  ₹20 / quintal
- Net Return:         ₹1,580 / quintal

Option 2: Individual Direct Buyer
- Gross Price:        ₹1,950 / quintal
- Deductions & Costs: ₹280 / quintal (High individual transport)
- Net Return:         ₹1,670 / quintal

Option 3: KrishiSetu FPO Aggregated Bulk Sale (WINNER)
- Gross Price:        ₹1,950 / quintal
- Deductions & Costs: ₹130 / quintal (Bulk shared transport)
- Net Return:         ₹1,820 / quintal

FINAL IMPACT DELIVERED:
- Net Advantage per quintal:  ₹1,820 - ₹1,580 = +₹240 / quintal
- Farmer Additional Income:   ₹240 * 20 quintals = +₹4,800 total profit
- Buyer Reliability Rating:   92%
- Payment Settlement Time:    Within 24 hours of delivery confirmation
